# RepForge Design System — change log

## v1.0 Stage 1 — 2026-11-02 — Brand reconstruction (for review)

Reproduced from the commission brief and branding board:
- RF monogram concept: light/slate R in front, amber F emerging from behind the R, italic slant, rounded geometry.
- Wordmark: Sora Bold, "Rep" neutral, "Forge" amber. Tagline in Manrope SemiBold caps.
- Palette: Forge Slate, Forge Amber, Steel, Stone, Mist, Sand and the four semantic colours, unchanged.
- App icon: rounded square, slate primary, amber and light variants.

Refinements proposed (need approval):
- Monogram rebuilt as vector geometry: 128 grid, stroke 26, 12° slant, R30 shoulders, R6/R3 corners.
- Primary buttons use Forge Slate labels on amber (white on amber fails WCAG AA).
- Dark muted text #8291A2 → #8E9DAE (4.5:1 on Surface 2).
- Light muted text uses #5E6E7F (Stone #6B7B8C is 4.3:1 on white).
- Added "Amber Ink" #B45F00 for amber text and links on light surfaces.
- Added amber interaction scale: hover #FFA033, pressed #E67C00, subtle tint 14%.
- Bottom navigation proposed as Home · Train · Fuel · Track · Goals.
