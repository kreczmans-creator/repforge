# Architecture Decision Records

Every significant architectural decision for RepForge is recorded here. Records are numbered, immutable once Accepted (a new ADR supersedes an old one), and linked from the work package that implements them.

Format: see `ADR-0001`. Required fields: ID, Title, Status (Proposed / Accepted / Deprecated / Superseded by ADR-xxxx), Context, Options considered, Decision, Rationale, Consequences, Date.

| ID | Title | Status |
|---|---|---|

| ADR-0002 | Adopt Flutter as the cross-platform framework | Proposed |
| ADR-0003 | Git tree, not ZIP archives, is the source of truth | Proposed |
| ADR-0004 | Local-first persistence with SQLite via drift; cloud sync deferred | Proposed |
